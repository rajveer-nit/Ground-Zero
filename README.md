## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/your-repo-name.git

# Navigate into the project directory
cd your-repo-name

# Install dependencies
npm install

# Run the development server
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

## 📁 Project Structure

```
├── public/          # Static assets (images, favicon, resume PDF)
├── src/
│   ├── components/  # Reusable UI components
│   ├── pages/        # Page-level components/routes
│   ├── styles/       # CSS/SCSS/Tailwind config
│   └── data/         # Resume content (experience, skills, projects)
├── README.md
└── package.json
```

## 📝 Customization

To make this your own:

1. Update personal info, experience, and skills in `src/data/`.
2. Replace images in `public/` with your own photo and resume PDF.
3. Update the color scheme and fonts in `src/styles/`.
4. Update social/contact links in the footer component.

## 📦 Deployment

This project is set up to deploy easily via:

```bash
npm run build
```

Then deploy the `build`/`dist` folder to your preferred host (Vercel, Netlify, GitHub Pages, etc.).
